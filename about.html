TimerCountdown

Таймер зворотного відліку для важливих подій

📋 Про додаток

TimerCountdown — це інструмент для створення та відстеження таймерів зворотного відліку. Додаток дозволяє задавати точний час старту та завершення будь-яких подій і відстежувати час, що залишився в реальному часі.

✨ Основні можливості:
  • ✔ Створення необмеженої кількості таймерів
  • ✔ Задання точного часу старту та завершення
  • ✔ Автоматичне оновлення часу в реальному часі
  • ✔ Візуальні індикатори статусу (очікує / активний / завершено)
  • ✔ Редагування та видалення таймерів
  • ✔ Автентифікація користувачів (реєстрація / вхід)
  • ✔ Персональний профіль кожного користувача
🎯 Для кого цей додаток:
  • Студенти — для відстеження дедлайнів
  • Бізнесмени — для контролю часу зустрічей
  • Спортсмени — для таймінгу тренувань
  • Кулінари — для приготування страв
  • Всі, хто хоче ефективно керувати своїм часом!
🛠 Технології:
  • HTML5, CSS3, JavaScript (ES6+)
  • Bootstrap 5 — адаптивний дизайн
  • REST API (json-server) — бекенд для зберігання даних
  • sessionStorage — зберігання стану авторизації
